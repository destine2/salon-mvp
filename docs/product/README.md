# Product documents

The source documents this MVP is scoped from. Copied in here (2026-08-16) so
they're version-controlled with the code and travel with a clone — they
previously lived only in a folder outside this repo, alongside unrelated
personal documents, which meant nobody who cloned the repo could see them.

| Document | What it is |
|---|---|
| `Salon_SaaS_PRD.docx` | The engineering spec. Section 8.1 has the stack rationale, 8.2 the original week-by-week build plan, section 9 the data model this schema is scoped from. |
| `Salon_SaaS_Nigeria_Business_Plan.docx` | Market research and business case — the "why this, why now" behind the PRD's problem statement. |
| `Salon_Owner_Discovery_Interview_Script.docx` | The interview script for validating the payment-integrity thesis with real salon owners, referenced in PRD section 10 as a dependency that hasn't been completed yet. |
| `Salon_Concept_One_Pager.docx` | The short-form pitch. |

**These are copies, not the canonical source** — if you edit the originals
elsewhere, these will drift. Given they're now in git, that drift is at least
visible in a diff rather than silent.

`ARCHITECTURE.md` (repo root) is the technical counterpart to these — written
from the code as it exists, not from the plan.
